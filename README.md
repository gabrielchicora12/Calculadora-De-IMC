# Calculadora-De-IMC
 📊 Calculadora de IMC  Uma aplicação web simples e funcional para cálculo e classificação do Índice de Massa Corporal (IMC).  ## 🚀 Tecnologias Utilizadas * **HTML5**: Estrutura da página. * **Bootstrap 5**: Estilização responsiva e componentes de interface. * **JavaScript**: Lógica de cálculo e validação dos dados.
